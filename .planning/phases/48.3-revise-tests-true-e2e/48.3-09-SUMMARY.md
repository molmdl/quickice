## Decisions Made

- **Real parser path over hand-rolled SimpleNamespace:** args come from `get_arguments` (create_parser + parse_args + validate_pipeline_args) with real flag values — authentic argparse defaults are the preconditions the auto-chain logic consumes, so they must be genuine. Pattern-4's empty `SimpleNamespace()` is still used for the export-isolation pipes (its `_run_export_step` reads no args).
- **Three-layer auto-chain pinning:** the plan's required observable (custom residue in exported solute.gro) is asserted, plus the `(source=custom)` progress line and the verbatim logger.info auto-chain records — the latter two are impossible in subprocess and document the upgrade decision itself, not just its output.
- **SEC-04 staging under `<cwd>/tmp/` for INPUTS even in-process:** etoh.gro/etoh.itp copied into a cwd-relative tmp dir (gitignored, cleaned in fixture teardown); only `pipe._output_dir` uses pytest tmp (SAFE-05 gates subprocess `--output`, not in-process attribute assignment).
- **Python 3.14 contextlib gotcha encoded in helpers:** `redirect_stderr` is stack-based (`_old_targets`); a manual `.__exit__()` after a `with` block pops an empty list → IndexError. Progress capture kept as an inline `with redirect_stderr(...)`, only the logging handler is factored into helpers.
