## Decisions Made

- **Inventory discipline:** ported exactly the asserts the sources made (plus structure-derived generalisations that are provably true — count parity from `ion.solute_n_molecules`/`custom_molecule_count` rather than hardcoded etoh==3); no invented asserts beyond the helper set applied to cross-combos.
- **Atom-conservation arithmetic mirrors the writer, not the structure:** discovered during Task 1 that interface-slab ice molecules carry 3 atoms in positions but `write_ion_gro_file` writes 4 (adds the TIP4P-ICE MW virtual site) — the helper's formula replicates `ordered_mols` accounting (ion_writer.py:199-218) so it is exact for every chain shape. The F1 source formula (`ice*4 + water*4 + custom + solute*5 + na + cl`) was already writer-aware; the helper generalises it via `molecule_index` walks instead of hardcoded per-type atom counts.
- **Focused cross-chain test is not gmx-gated:** its asserts are pure file-parses, so coverage survives on machines without GROMACS (per plan verification note "file-level asserts always run"); the same chain shapes remain grompp-validated by the per-chain classes.
