### Audit exception handled: `test_e2e_mixed_ion_export.py`

**Investigation finding:** the file (45-15 mixed CH4+THF ion-export regression) called `_stage_hydrate_guest_itps` + `write_ion_gro_file` + `write_ion_top_file` directly — but the real `InterfaceGROMACSExporter.export_ion_gromacs` flow (gui/export.py:580-658) performs FIVE steps: the test's three, **plus `write_ion_itp` (ion.itp) and the `tip4p-ice.itp` copy**. The ion .top `#include`s both (`ion_writer.py:896` tip4p-ice, `:951` ion.itp), so the mirrored export was INCOMPLETE and could not have passed grompp — exactly the fake-e2e pattern the phase hunts.

**Fix applied (test-only):** `_export_to_dir` now mirrors the FULL real flow (adds `write_ion_itp` + `shutil.copy(get_tip4p_itp_path(), ...)`), then grompp-validates the complete export dir (`shutil.which("gmx")`-guarded per the 48.3-07/08 convention). This also strengthens the regression: the 45-15 bug class was staging completeness, and the test now proves the complete staged export is grompp-valid.

**Verification:** file 7/7 green (1.66s) with gmx present — grompp genuinely executed, rc==0 asserted.
