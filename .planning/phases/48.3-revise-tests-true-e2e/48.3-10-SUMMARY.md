### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed MOL_H .gro molecule counting in the parity helper**

- **Found during:** Task 2 (first test run: all 12 new cases failed the parity assert)
- **Issue:** The first implementation counted contiguous RUNS of "MOL_H" residue entries as the .gro molecule count — wrong: consecutive same-type molecules form ONE contiguous run (384 molecules = 1 run of 3456 atom entries). The exports themselves were correct (.top count 384 == slab truth 384); only the test-side counter was broken.
- **Fix:** Derive the .gro molecule count as atom-level residue entries `// config.guest_atom_count` (atoms per molecule from the config — never hardcoded), with a divisibility assertion to catch partial/mangled molecules.
- **Files modified:** tests/test_e2e_custom_guest_lattices_gui.py
- **Verification:** all 16 tests pass (4 old + 12 new); .top == .gro == slab-truncated guest_nmolecules in every case
- **Committed in:** 27e9dafb (Task 2 commit)
