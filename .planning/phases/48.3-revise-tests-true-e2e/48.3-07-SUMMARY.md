## Decisions Made

- **D2 pin test targets the CLI HYDRATE branch** (not the plan's literal "interface export branch"): the CLI interface branch is mixed-capable since b278a9ed (slab carries `guest_atom_counts` + `guest_descriptors`; proven by 48.3-05's committed passing test `test_mixed_interface_cli_branch_declares_both_guests_grompp`), so a single-stream assert there is unimplementable. The LIVE limitation is the hydrate branch — its `InterfaceStructure` wrapper (pipeline.py hydrate branch) never threads the metadata, so `write_interface_*` falls back to the single `detect_guest_type_from_atoms` pass. This matches D2's own downstream-implication row ("one guest ITP staged / one guest moleculetype in [molecules]") and its cross-reference to 48.3-05's mixed interface tests. Empirically verified before writing the test (probe: SOL 136 + CH4_H 24; 184 CH4_H guest atoms; thf ITP absent; grompp rc=1 "number of coordinates (728) does not match topology (664)").
- **test_hydrate_only uses 2×2×2 supercell**: the default 1×1×1 sI box (~1.2 nm) is shorter than 2×rcoulomb (em.mdp cutoff 1.0 nm) → grompp fatals "The cut-off length is longer than half the shortest box vector" (documented Pitfall 1 in test_e2e_filled_ice_cli_hydrate_grompp.py). 2×2×2 = 2.4 nm passes; measured subprocess ~1.0s, grompp rc=0 no warnings.
- **Pocket+ion grompp is conditional (0-ion production gap discovered, NOT fixed)**: pocket mode's default thin liquid layer (3258 ice + 105 water ≈ 3.1 nm³) yields 0.15 M × 3.1 × 0.6022 ≈ 0.28 → 0 ion pairs — legitimate math, not a bug. But the 0-ion export still stages + `#include`s `ion.itp` while `write_ion_top_file` emits NO NA/CL atomtypes → `gmx grompp` fatals "Atomtype NA not found" (ion.itp line 8, orphan include; slab runs pass because ≥1 ion pair triggers NA/CL atomtypes in the .top). Production fix is out of scope for this test-only phase ("never modify production code in this plan"); the test pins the 0-ion state and grompp-validates whenever ions ARE placed.
- **No-op flags removed from existing grompp tests**: `--gromacs -g --no-diagram` are parser-only plumbing (pipeline.py never reads them) — removed per the plan's research §5 note.
